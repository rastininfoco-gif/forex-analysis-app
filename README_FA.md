# راهنمای فارسی ساخت APK برای پروژه Forex

## این نسخه چه چیزی را آماده کرده؟
- فایل `requirements.txt` برای نصب کتابخانه‌های Python
- تنظیم پیشنهادی استقرار در Render (`render.yaml`)
- `manifest.json`، آیکون‌های برنامه و Service Worker برای آماده‌سازی PWA
- مسیرهای لازم برای دسترسی به manifest و service worker

## مرحله ۱: بارگذاری در GitHub
1. به https://github.com بروید و یک حساب بسازید/وارد شوید.
2. روی New repository کلیک کنید و نامی مانند `forex-analysis-app` بگذارید.
3. فایل‌های داخل همین ZIP را استخراج کنید.
4. در صفحه مخزن، Add file > Upload files را بزنید و تمام فایل‌ها و پوشه‌های استخراج‌شده را بارگذاری کنید؛ خود پوشه‌ی بالایی را دوباره تو در تو بارگذاری نکنید.
5. Commit changes را بزنید.

## مرحله ۲: اجرای سرور در Render
1. به https://render.com بروید و ثبت‌نام کنید.
2. New + > Web Service را بزنید و مخزن GitHub را وصل کنید.
3. تنظیمات:
   - Runtime: Python
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`
   - اگر گزینه‌ی پلن رایگان نشان داده شد، می‌توانید برای آزمایش آن را انتخاب کنید.
4. Create Web Service را بزنید و منتظر بمانید Deploy موفق شود.
5. آدرس HTTPS که Render می‌دهد را باز کنید. اگر صفحه بالا آمد، `/api/symbols` را هم به انتهای آدرس اضافه کنید؛ باید داده‌های JSON نمادها دیده شود.

## مرحله ۳: ساخت APK
1. پس از آن‌که سایت روی HTTPS درست اجرا شد، به https://www.pwabuilder.com بروید.
2. آدرس HTTPS برنامه را وارد کنید و Start را بزنید.
3. اگر اخطارهایی درباره PWA داد، آن‌ها را بخوانید؛ اگر manifest یا service worker شناسایی نشد، اول باید همان مشکل را رفع کنیم.
4. Package for stores > Android > Generate Package را انتخاب کنید و گزینه‌های بسته‌بندی را دنبال کنید.
5. برای آزمایش روی گوشی، فایل APK امضاشده را انتخاب/دانلود کنید. برای انتشار در Google Play شرایط امضا و تنظیمات بیشتری لازم است.

## نکات مهم
- نسخه‌ی رایگان سرویس میزبانی ممکن است پس از مدتی بی‌استفاده‌ماندن به خواب برود؛ اولین بازشدن بعد از آن می‌تواند کند باشد.
- برنامه برای دریافت قیمت‌ها و اخبار به اینترنت وابسته است؛ حالت آفلاین فقط می‌تواند بخش‌هایی از رابط را نگه دارد.
- این برنامه تحلیلی است و سیگنال‌هایش تضمین سود یا توصیه سرمایه‌گذاری نیستند.
- این پکیج آماده‌سازی اولیه است؛ هنوز در یک حساب میزبانی واقعی Deploy نشده و APK نهایی ساخته نشده است.
